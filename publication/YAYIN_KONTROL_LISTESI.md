# Yayın Kontrol Listesi

## Yerel olarak tamamlananlar

- [x] FP32, FP16 ve INT8 engine'leri mevcut RTX 5060 Laptop GPU'da yeniden oluşturuldu.
- [x] Hız ölçümleri tek protokolle 10 bağımsız tekrar üzerinden alındı.
- [x] COCO val2017 üzerindeki doğruluk ölçümü 5.000 görüntüyle tamamlandı.
- [x] Makale için anonim Türkçe taslak hazırlandı.
- [x] Ücretsiz GitHub Pages tanıtım sayfası hazırlandı (`docs/`).
- [x] Resmî 2026 CDEJ Word şablonu indirildi ve eski, yanlış adlandırılmış şablon işaretlendi.
- [x] Mevcut 4. hafta demo videosu tanıtım sayfasına bağlandı.

## GitHub için

- [ ] Yazarın GitHub hesabında herkese açık depo oluştur.
- [x] AGPL-3.0 lisansını seç ve `LICENSE` dosyasını ekle.
- [ ] Kaynak kodu gönder; makineye özgü `.engine`, veri kümesi, sanal ortam ve logları gönderme.
- [ ] Settings → Pages → Deploy from a branch → `main` / `docs` seç.
- [ ] Oluşan Pages adresini README, makale ve Zenodo kaydına ekle.
- [ ] Sürüm etiketi oluştur: `v1.0.0`.

## Zenodo DOI için

- [ ] GitHub hesabını Zenodo'ya bağla ve depoyu etkinleştir.
- [ ] GitHub'da `v1.0.0` release yayımla; Zenodo arşivi ve DOI'yi üretsin.
- [ ] Başlık, yazar adı, ORCID, özet, anahtar kelimeler ve lisansı kontrol et.
- [ ] DOI'yi `CITATION.cff`, README ve makalenin Veri/Kod Erişilebilirliği bölümüne ekle.

## CDEJ gönderimi için

- [ ] Yazar bilgili Word dosyasını resmî şablonda tamamla.
- [ ] Yazar ve kurum bilgileri kaldırılmış anonim Word dosyasını oluştur.
- [ ] Benzerlik raporunun kaynakça hariç en fazla %25 olduğunu doğrula.
- [ ] Telif hakkı formunu imzalı PDF olarak hazırla.
- [ ] Danışman/hoca kontrolünden yazılı onay al.
- [ ] DergiPark sistemine makale, anonim kopya, telif formu ve gerekli ekleri yükle.

## Tamamlamak için yazardan gereken bilgiler

- Fakülte/yüksekokul bilgisi (makale şablonu gerektirirse)
- Staj yapılan kurum ve tarih aralığı
- Demo videosunun kesin kaynak/lisans bilgisi veya yazarın kendi kaydı olduğuna dair doğrulama

> DOI ancak Zenodo kaydı yayımlandığında kesinleşir. Gönderim ve yayımlama işlemleri kullanıcı hesabı üzerinden yapılmalı; danışman kontrolünden önce dergiye gönderilmemelidir.
